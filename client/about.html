The Engineering Behind PostYourJobUK

PostYourJobUK is a cloud-native, multi-tenant AI recruitment Software-as-a-Service (SaaS) and Applicant Tracking System (ATS) engineered to solve two critical industry challenges: prohibitive enterprise ATS licensing costs for UK SMEs and black-box algorithmic bias in automated CV screening.

🏢 Multi-Tenant Isolation & Zero-Trust Security

Built on a decoupled Three-Tier architecture (client/ Presentation Tier + server/ REST API Tier) enforcing strict tenant_id BOLA database scoping, Zero-Trust session fingerprinting (User-Agent + SHA-256 IP hash), and timing-safe CSRF token verification.

🧠 Two-Stage Decoupled AI Evaluation

Candidate CVs undergo Stage 0 regex PII redaction before factual claim extraction via Google Gemini 2.5 Flash at temperature = 0.0. Every claim is verified character-for-character by a deterministic Python Grounding Gate (difflib anti-plagiarism + timeline overlap merging) and scored via Base-100 subtractive math.

⚡ Event-Driven Serverless Azure Ecosystem

Web ingestion (postyourjobuk-web on Azure App Service) is decoupled from heavy document processing via Azure Blob Storage (hranalyticalstorage), Azure Storage Queues (ai-processing-queue), Python 3.11 Azure Functions (postyourjobuk-ai-func), Azure Key Vault (kv-postyourjobuk), and Azure MySQL Flexible Server.

✉️ Automated ATS Pipeline & Brevo Transactional SMTP

Recruiters transition candidates across Reviewed, Interviewing, Hired, and Rejected stages with 1-click automated HTML emails dispatched via PHPMailer and Brevo SMTP Relay (authenticated with Cloudflare SPF, DKIM, and DMARC) embedding live employer business cards.

⚖️ Live Counterfactual Fairness Testbed (Tenant 9999)

Features a dedicated Super-Admin compliance workspace that dispatches 18 synthetic CVs across 9 protected demographic pairs into the live Azure Queue, providing a 4-tab Counterfactual Evidence Inspector and SHA-256 signed PDF Compliance Certificates.

📊 Executive Analytics & Zero-CDN Vector CV Builder

Provides candidates with a 100% private, 6-template client-side Resume Builder that compiles native PDF-1.4 vector text streams for PyPDF2, alongside 12 interactive HTML5 <canvas> charts across the Recruiter and Super-Admin analytics suites.
